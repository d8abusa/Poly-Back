PLATFORM CONTEXT
═══════════════════════════════════════════════════════════

Full stack:
  Backend:
    - Python 3.12, FastAPI 0.110+, Uvicorn 0.29+
    - Pydantic v2 for all data models

    - Entry point: backend/main.py

    - BacktestRequest: strategy params as optional fields
      (zscore_window, kelly_fraction, mm_spread + defaults)

═══════════════════════════════════════════════════════════
CODE STANDARDS
═══════════════════════════════════════════════════════════

Python:
  - Type hints on all function signatures
  - Pydantic v2 models for all API boundaries
  - Async/await throughout (no sync blocking in FastAPI routes)
  - Explicit error handling — no bare except clauses
  - Single responsibility per service function

TypeScript/React:
  - Strict TypeScript — no implicit any
  - Props interfaces defined for every component
  - useCallback/useMemo for expensive operations in renders
  - API response types defined and validated before use
  - Recharts: consistent color palette and axis formatting

General:
  - Functions < 50 lines where possible; extract if longer
  - No magic numbers — use named constants
  - Every new API endpoint documented in docstring
  - Breaking changes flagged explicitly to the team

CONSTRAINTS
